# SimpleFactions

## Commands

| Command | Description |
|---------|-------------|
| `/sf` | Opens the Simple Factions menu. |
| `/sf help` | Displays all available faction commands. |
| `/sf create <name>` | Creates a new faction with the specified name. |
| `/sf delete` | Deletes your current faction. *(Owner only)* |
| `/sf owner` | Shows the owner of your current faction. |
| `/sf owner <faction>` | Shows the owner of the specified faction. |
| `/sf members` | Lists the members of your current faction. |
| `/sf members <faction>` | Lists the members of the specified faction. |
| `/sf invite <player>` | Invites a player to join your faction. |
| `/sf leave` | Leaves your current faction. |
| `/sf kick <player>` | Removes a player from your faction. *(Owner only)* |
| `/sf list` | Displays all existing factions. |
| `/sf modify name <name>` | Renames your faction. *(Owner only)* |
| `/sf modify color <color>` | Changes your faction's colour. *(Owner only)* |
| `/sf modify owner <player>` | Transfers faction ownership to another member. *(Owner only)* |
| `/chat public` or `/cp` | Switches to public chat. |
| `/chat faction` or `/cf` | Switches to faction chat. |
